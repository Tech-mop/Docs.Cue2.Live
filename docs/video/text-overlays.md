# Text overlays

**Text components** draw on a target layer using a clipped rich-text label.

## Fields

| Field | Notes |
|-------|-------|
| Content | Plain text or BBCode when enabled |
| Use BBCode | Interpret markup |
| Target layer | −1 = no output |
| Duration | Seconds; **0 = until stopped** |
| Alignment | Horizontal + vertical |
| Font size | Pixels |
| Font name | System family (portable by name) |
| Font path | Optional `.ttf`/`.otf` override |
| Colour / opacity | Independent alpha concerns |
| Autowrap / margins | Layout inside layer |
| Outline | Thickness for readability |
