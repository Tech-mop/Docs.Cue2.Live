# Video troubleshooting

| Problem | Checks |
|---------|--------|
| **Black output** | Target layer set; output window visible on correct monitor; opacity; test pattern sanity |
| **Wrong place** | Layer rect; screen placement on canvas; expand/stretch mode |
| **Dropped frames** | Prefer performance; reduce layers; disk; quality mode |
| **Tearing** | Prefer VSync |
| **Preview poor, output fine** | Preview quality half/quarter — expected |
| **No audio with video** | Embedded audio enabled; audio patch assigned |
| **Subtitles missing** | Text-based only; correct stream/sidecar; not bitmap |
