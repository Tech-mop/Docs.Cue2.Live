# Control seek

Seek control moves playing audio/video on the target cue.

| Mode | Meaning |
|------|---------|
| Absolute | Jump to time T seconds |
| Relative | Offset by ±Δ seconds |

Equivalent network forms exist under OSC (`/Seek…`, `/SeekRel…`).
