# Cue light components

| Action | Purpose |
|--------|---------|
| **Go** | Signal GO with optional cue number context |
| **Standby** | Standby indication |
| **Count in** | Count-in with time parameter |
| **Identify start/stop** | Identify the device |
| **Cancel** | Cancel current indication |

Devices are configured under settings; components reference a cue light id.
