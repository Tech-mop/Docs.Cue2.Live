# Control cues

## Steps

1. Create **Cue A** with audio or video so you can see/hear a change.  
2. Create **Cue B** as a control cue: add a **Control** component.  
3. Set action **Stop** (or **Fade** volume to 0 over 2 seconds).  
4. Target **Cue A** by id or cue number.  
5. GO A, then GO B.

## Ideas

- **Start now** to punch out of pre-wait  
- **Seek** for safety jumps  
- **Translate layer** for simple motion on canvas layers  
- Multiple control components on one shell for parallel actions
