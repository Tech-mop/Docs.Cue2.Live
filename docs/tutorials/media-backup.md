# Portable show folder

## Steps

1. Save your session to a dedicated show folder.  
2. Enable **Media backup** in Settings → General (default is on).  
3. Add media and save; or use **Show Files → Copy Media into Show Folder**.  
4. Confirm `Audio/`, `Video/`, and/or `Images/` appear beside the `.c2`.  
5. Use **Check File Presence** if anything looks missing.  
6. Zip/copy the whole folder to another machine.
