# Multi-screen canvas

## Steps

1. Open **Settings → Canvas editor**.  
2. Set canvas pixel size to your virtual stage (e.g. 3840×1080 for two 1080p projectors side by side).  
3. Add **screens** for each physical output window; position them on the canvas.  
4. Add **layers** sized/positioned where content should appear.  
5. Lock layers you do not want to nudge accidentally.  
6. Enable **test pattern**, align physical displays, then disable.  
7. Point video/text components at the correct **layer ids**.
