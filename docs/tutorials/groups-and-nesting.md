# Groups and nesting

## Steps

1. Create several cues.  
2. Multi-select them.  
3. **Edit → Group Selected** (Ctrl+G).  
4. Collapse/expand with `-` / `=` or `.` for all.  
5. Drag to reorder within the group as needed.

## Remember

Continue/Follow targets the **next sibling at the same level**, not “whatever is next visually” across parents.
