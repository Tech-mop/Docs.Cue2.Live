# Cue2 Preferences

Stored in user data — **not** in the showfile and **not** undo-tracked.

| Preference | Notes |
|------------|-------|
| **Language / locale** | en, mi, es (as shipped); restarts not always required — UI re-localises on change |
| **Keyboard Input Map** | Rebind project actions; persists live map |
