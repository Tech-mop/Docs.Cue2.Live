# Component defaults

## Audio

| Field | Factory |
|-------|---------|
| Volume | 1.0 |
| Pan | 0 (center) |
| Loop | false |
| Play count | 1 |
| Fade in/out | 0 |
| Output mode | Preferred patch |

## Video

| Field | Factory |
|-------|---------|
| Expand | IgnoreSize |
| Stretch | KeepAspectCentered |
| Opacity | 1 |
| Loop | false |
| Play count | 1 |
| Use embedded audio | true |
| Target layer mode | First available / specific / none |

## Text

Typography, alignment, duration, style, and fades as configured in Text defaults UI (system defaults mirror inspector factory values).
