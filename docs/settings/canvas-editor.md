# Canvas editor

Visual editor for the display graph.

| Task | How |
|------|-----|
| Resize canvas | Canvas size fields |
| Add screen | Screen tools; position on stage |
| Add layer | Layer tools; set rect |
| Lock layer | Property toggle |
| Align outputs | Enable test pattern |

Drag geometry coalesces into one undo step per gesture. History key: `Displays`.
