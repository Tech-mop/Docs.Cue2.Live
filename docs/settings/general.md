# General settings

| Setting | Default | Notes |
|---------|---------|-------|
| UI scale | 1.0 | Overall UI |
| GO scale | 1.0 | `0` hides GO header; `0.5` half GO layout |
| Cuelist scale | Medium (1.0) | Small 0.85 / Large 1.25 |
| Waveform resolution | 4096 bins | Peak generation density |
| Stop fade duration | 2.5 s | Soft stop length |
| Media backup | On | Copy media into show folder |
| Multi-edit | On | Shell multi-select edits |
| Select new cues | On | Focus newly created cues |
| Show mode | Off | When on, live/show lock behaviour for edits |
| Timeline waveforms | On | Draw peaks in timeline bars |
