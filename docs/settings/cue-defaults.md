# Cue defaults

Applied when creating new cues (`Settings.ApplyShellDefaults`).

| Default | Factory |
|---------|---------|
| Pre-wait | 0 |
| Post-wait | 0 |
| Follow | None |
| Colour | Black |
| Armed | true |
| Skip if disarmed | false |
| Only one active instance | false |
