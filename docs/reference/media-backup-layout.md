# Media backup layout

When media backup runs, files land next to the showfile:

```text
MyShow/
  MyShow.c2
  Audio/
  Video/
  Images/
```

Cue paths rewrite to show-relative forms such as `Audio/song.wav`. Progress appears in the footer via backup signals.
