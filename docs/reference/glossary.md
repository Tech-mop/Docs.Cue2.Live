# Glossary

| Term | Definition |
|------|------------|
| **Active cue** | A live playback instance (or armed incoming sequence member) |
| **Armed** | Cue is allowed to play content on GO |
| **Canvas** | Virtual pixel stage for screens and layers |
| **Component** | Payload on a cue (audio, video, …) |
| **Cuelist** | Ordered list of cue shells |
| **Direct output** | Audio device name without a patch object |
| **Follow mode** | None / Continue / Follow sequencing |
| **GO** | Start the selected/playhead cue sequence |
| **Layer** | Drawable target rectangle on the canvas |
| **Patch** | Audio output mapping table |
| **Playhead** | Cue that receives standard GO advancement |
| **Post-wait** | Delay before a continued/followed next cue starts |
| **Pre-wait** | Delay after start before content |
| **Screen** | Output window region of the canvas |
| **Session** | Live show state; saved as `.c2` |
| **Shell** | Cue identity + timing + triggers without requiring media |
| **Show settings** | Document settings inside the showfile |
| **Skip if disarmed** | Bypass disarmed cues when advancing playhead |
